# Despliegue

La aplicación se entrega en Dockerfiles de API y web. Despliega PostgreSQL y Redis privados, crea un usuario de base de datos propio, realiza respaldo periódico del volumen y configura `DATABASE_URL`, `REDIS_URL`, `AUTH_SECRET`, `COOKIE_SECRET`, `WEB_URL`, `API_URL`, `NODE_ENV=production` y las variables Meta si corresponde. Si utilizas el Compose incluido, cambia `POSTGRES_DB`, `POSTGRES_USER` y `POSTGRES_PASSWORD` (contraseña URL-safe), pues Compose construye la URL interna desde esos valores; el `DATABASE_URL` de `.env.example` sirve para comandos ejecutados fuera de Docker. Ejecuta `prisma migrate deploy` antes de iniciar API. No ejecutes el seed de demostración en producción. Para una base nueva, define `ADMIN_INICIAL_CORREO` y `ADMIN_INICIAL_PASSWORD` y ejecuta una vez `npm run bootstrap:admin -w apps/api` dentro del contenedor API. El comando rechaza crear otro administrador si ya existe uno. Después retira `ADMIN_INICIAL_PASSWORD` del entorno si fue temporal.

Publica web y API bajo HTTPS con el origen exacto configurado en `WEB_URL`. `API_URL` debe ser accesible desde el navegador; se inyecta al construir Next.js. La cookie es Secure en producción. El endpoint `/salud` comprueba PostgreSQL y Redis sin revelar secretos. El callback es `https://<DOMINIO_PUBLICO_DE_API>/webhooks/meta/whatsapp`.

Esta V1 usa un solo proceso API: SSE publica cambios en memoria y el worker BullMQ está dentro de ese proceso. Antes de escalar horizontalmente, mueve la distribución SSE a Redis Pub/Sub y separa el worker. Protege logs, configura observabilidad y revisa la política de mensajes de Meta: respuestas libres fuera de la ventana de atención pueden requerir plantillas aprobadas. La [referencia oficial de Meta](https://www.postman.com/meta/whatsapp-business-platform/folder/fuaee8l/statuses-object) explica la ventana de atención.

No expongas PostgreSQL ni Redis a Internet. No publiques el simulador: se bloquea con `NODE_ENV=production`. Verifica restauración de respaldo, CORS, webhook firmado, pruebas de concurrencia y permisos antes de abrir al público.
